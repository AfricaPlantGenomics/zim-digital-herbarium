# SRGH Herbarium — Digital Collection

**[Access the web app](https://cwr.africanplantgenomics.org/)**

A web app for exploring the Zimbabwe Natural History Museum's Crop Wild Relatives herbarium collection. Browse, search, and map over 1,500 plant specimens collected across Zimbabwe from 1902 to 2019.

---

## What's in the collection

- **1,513 specimens** collected over more than a century
- **580 georeferenced** specimens you can explore on an interactive map
- **550 collectors**, across **54 modern districts** and **314 historical districts**
- Every specimen classified using the IUCN habitat framework
- Specimen images stored alongside full label transcriptions and field notes

## What you can do

**Map** — see where specimens were collected across Zimbabwe, draw a box to filter by area, and click any pin for details.

**Table** — sort the full collection by species, collector, date, altitude, district, or habitat type.

**Gallery** — browse specimen images and jump straight to any record.

**Search** — find specimens by species name, habitat, locality, or collector notes.

**Filters** — narrow the collection by district, habitat, date range, altitude, or a drawn map area. Export any filtered view.

**Specimen detail** — each record shows full metadata: geographic information, phenotype, flowering state, altitude, habitat classification, and label field notes.
